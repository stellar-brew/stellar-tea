# swap-client JS

JS library for interacting with [Soroban](https://soroban.stellar.org/) smart contract `swap`
via Soroban RPC.

This library was automatically generated by Soroban CLI using a command similar to:

```bash
stellar contract bindings typescript \
  --wasm target/wasm32v1-none/release/swap.wasm \
  --output-dir ./packages/swap-client
```

The network passphrase and contract ID are exported from [index.ts](./src/index.ts) in the
`networks` constant. If you are the one who generated this library and you know that this
contract is also deployed to other networks, feel free to update `networks` with other valid
options. This will help your contract consumers use this library more easily.

The package is part of the `stellar-tea` pnpm workspace and is consumed by the frontend through
`frontend/src/lib/contracts/swap.ts`, which imports `Client`, `networks` and `TeaMetadata`.

# Use it

Import the generated client and build an RPC client with your own `rpcUrl`:

```js
import { Client, networks } from "swap-client";

const client = new Client({
  ...networks.testnet,
  rpcUrl: "https://soroban-testnet.stellar.org",
});

await client.mint_tea({ caller, recipient, tea_metadata });
```

As long as your editor is configured to show JavaScript/TypeScript documentation, you can pause
your typing after `client.` to get a list of all exports and inline-documentation for each
method. It exports a separate [async](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/async_function)
function for each method in the smart contract.
